# Albion Trade Intelligence — downloads

Windows desktop app for Albion Online: market flipping, cross-city trade, Black Market flipping, Roads of Avalon and a damage meter.

**[Download the latest version](https://github.com/ugurc4n/albi-update/releases/latest)** — run `AlbionTradeIntelligence-Setup-<version>.exe`.

- One-click install, no administrator rights needed.
- Windows may show "Windows protected your PC" the first time: choose *More info → Run anyway*.
- The app updates itself: new versions download in the background and install when you close it, or right away with **Restart to update** in the sidebar.

This repository only hosts the installers; there is no source code here.
